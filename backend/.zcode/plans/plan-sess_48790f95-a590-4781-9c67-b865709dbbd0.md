## Goal
Add unit tests for every untested package in the project, using fast deterministic mocks (no DB / no SMTP / no network). Mock style matches the existing suites: hand-rolled function-field doubles, plain `testing`, table-driven where it reads well.

## Strategy by layer
- **Pure utilities** → direct calls + table tests.
- **Services** (auth/user/tenant/email) → mock the `repository.*Repo` and `email.EmailService` **interfaces** (which already exist), inject via the `New*` constructors.
- **HTTP handlers** → mock the service interfaces (`AuthService` / `UserService` / `TenantService`), drive via gin + `httptest.Recorder`; set/clear `ctxutil` context keys to exercise the auth-gated branches.
- **Mailer async/email** → wrap a signaling fake `Mailer` (closes a channel from inside `Send`) so goroutine completion is observed deterministically (no flaky sleeps); reference internal consts (`maxAttempts`, `retryDelay`).
- **SMTP** → only the pre-network validation branches (invalid From/To/ReplyTo); the real send needs a live server (integration).
